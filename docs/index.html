01 — The idea

Why meet in bird’s-eye view?

A camera is dense in appearance but ambiguous in depth. LiDAR is sparse in appearance but precise in 3D. BEVFusion turns both into features indexed by the same ground-plane coordinates. Once a cell means the same physical patch of road in both branches, fusion becomes ordinary channel concatenation.

BEVBird’s-eye view: a top-down metric grid. The high-resolution camera grid is 360 × 360 at 0.3 m per cell; the fused detection grid is 180 × 180.

03 — Operator decomposition

The camera branch: learn depth, then lift.

Swin-T extracts multi-scale image features. An FPN returns them to a common width. The depth head predicts a categorical depth distribution and a context vector for every image location. Calibration turns each image-depth pair into a BEV cell.

“Lift” creates depth-weighted features along camera rays; “splat” sums contributions landing in the same ground cell.

The LiDAR branch: preserve sparsity.

Points are deterministically grouped into voxels. MeanVFE averages at most ten points per voxel. Twenty-one sparse convolutions reuse coordinate maps, then height compression creates a dense [1,256,180,180] tensor only at the branch boundary.

TransFusion: ask the map for objects.

Image and LiDAR BEVs concatenate to 336 channels. A dense backbone produces a shared feature and class heatmap. The top 200 locations become queries; attention, an FFN, and six heads decode metric center, dimensions, rotation, velocity, class, and score.

04 — Residency

Move tensors at the boundary, not between operators.

A fast kernel cannot rescue a graph that repeatedly returns to the host. CUDA uploads BFI inputs once, owns reusable weights and scratch, and copies back only canonical detections.

05 — Optimization worklog

Every fast idea passes through an oracle.

The scalar route stays as reference. A candidate is promoted only when the relevant complete slice remains within tolerance. Several intuitively good ideas lost.

Portable CPU graph209.32 → 11.71 s
scalar oracleOpenMP + SIMD-friendly loops

Keep the scalar dense kernels switchable, then parallelize output ownership, reuse sparse coordinate lookups, remove padding branches, and vectorize contiguous reductions. Generic Netlib BLAS regressed and is not auto-selected.

CPU proposal selection2,833 → 8.2 ms
repeated scan + prior searchbounded 200-entry heap

One stable top-k scan replaces an O(N·K²) search while preserving score order and the original flat-index tie rule. The complete TransFusion checkpoint oracle still passes.

LSS pooling85.58 → 1.75 ms
atomic geometrystable intervals

Sort contributions into stable cell intervals. One block reduces each interval, removing atomics and full XYZ materialization. Precomputed ranks with the same atomics regressed to 92.98 ms.

Swin-T87.75 → 58.06 ms
one queryshared K/V + bounded chunks

Reuse K/V and bound FFN/window scratch. Residency fell from 393.73 to 216.27 MiB. A larger 16-query tile and TF32 both failed their gates.

TransFusion attention22.47 → 17.16 ms
one query / block8 query warps

Online softmax stores one stable (m, l) pair per query and head. Eight query warps won; sixteen regressed. Fast __expf stays explicitly approximate.

06 — Reproduce it

Start small. Add dependencies only when needed.

  1. 1

    Prove the portable core

    make doctor
make ENABLE_CUDA=0 test

    No dataset, checkpoint, Python package, or GPU is required.

  2. 2

    Download the required checkpoint

    export NUSCENES_ROOT=/data/nuscenes
mkdir -p "$NUSCENES_ROOT/checkpoints"
# save as checkpoints/cbgs_bevfusion.pth

    Download cbgs_bevfusion.pth from Google Drive. It is an external asset and is not covered by the repository MIT License.

  3. 3

    Prepare offline tools

    python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements/demo.txt

    This adds NumPy, Pillow, and the nuScenes devkit.

  4. 4

    Pack frames and export weights

    export NUSCENES_ROOT=/data/nuscenes
make demo-data
make model

    PyTorch is required only for model export and oracle generation.

  5. 5

    Require the accelerator

    make ENABLE_CUDA=1 CUDA_ARCH=sm_89
make cuda-test

    Change the architecture for the target GPU. Explicit mode stops on incomplete CUDA/cuDNN.

07 — What the numbers mean

Equivalence is not dataset accuracy.

Kernel fixtures prove an operator. Matching raw outputs proves the frozen graph. Official mAP/NDS requires results tied to nuScenes sample tokens and evaluated with the official protocol. BFI v1 omits that global metadata, so this project does not turn a convincing demo into an unsupported accuracy claim.

Optimize the actual bottleneck, preserve a reference path, and attach every claim to numerical evidence.
